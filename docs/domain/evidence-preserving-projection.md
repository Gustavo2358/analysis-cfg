# EP-W5 — admission is a precision choice, not a recall gate

Four independent RED contrasts add a partial memory effect, unknown declaration,
non-modeled invocation outcome or unavailable unrelated unit to a program whose
computed target is supported by an executed assignment. All currently lose PROGA.
The W4 literal fallback therefore does not prove the full information-addition law.

## Decision before production

1. Scalar values is an optimization for a closed admitted profile. A semantic
   admission refusal selects the existing regional provider before execution.
   Invalid input is still rejected. An admission probe executes no solver. The
   existing single selected provider runs once per Entry and queries its stable
   state; there is no second value implementation or query reseeding.
2. Add explicit PARTIAL_ANALYSIS projection policy for evidence consumers. It
   preserves original AIR occurrences and known supported local edges. Missing
   unit bodies have no invented entry/sequence. Their declarations remain in the
   same index, including possible aliases; available independent entries run.
3. An unmodeled terminator/outcome contributes conservative local control
   uncertainty in the existing lazy contextual cursor. Known Normal edges remain
   explicit. Other possible edges have unknown execution and cannot grant MUST
   outcome authority. No physical fallthrough, text/name dispatch, new COBOL
   capability or replacement AIR is introduced. Existing strict policies retain
   their original admission contract.
4. The same AIR memory envelopes and existing RD/regional transfer semantics
   apply on those paths. Unknown control is not a NOP. Results disclose partial
   projection reasons and open control/source remainder. Structural invalidity,
   uncompleted validation and unknown mandatory AIR capability remain rejection
   or explicit partial inventory limits; they are not silently treated as valid.

## Cost and contracts

Admission adds at most one scalar preparation probe before the selected existing
provider is prepared. It changes constants, not complexity, and does not solve.
Known graph construction remains linear in its output. Unknown successors remain
lazy over the unit, as with existing bounded open control; no dense graph retained.
The same worklist solver handles the enlarged graph. The selected dependency
product uses existing JSON 1.2.0 partial status/reasons; AIR 2.0.0 and bindings do
not change. CFG policy is a consumer contract change, not source semantics.

## Required counterproof

Each addition above must preserve the previous candidate and its producer;
unknown scopes cannot turn into disjointness. Missing body plus multiple units
must retain both computed support and literal DIRECT. Unknown control must widen
execution, while exact executed writes on a modeled path remain the only kills.
Existing strict CFG refusal controls and structural invalidity must still pass.
