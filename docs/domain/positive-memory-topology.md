# Positive memory topology — W1

The supported AIR projection is the executable model. Coverage/Evidence/Precision
metadata records omitted source aspects; it neither adds effects nor authorizes a
consumer to erase published Unknown, Choice, MAY, scopes or control alternatives.
Invalid references/types/ranges and unsupported executable operations remain errors.

StorageId is a state identity. Distinct bases are independent; same-base intersecting
ranges and positive Alias/Alternatives bindings retain sharing. Object and Unit IDs
are not storage identities. Lifetime/context and exact-write authority are unchanged.
No DisjointStorage premise is needed; redundant assertions remain validated wire data.

StatementEffects prepares only direct destinations and explicitly scoped effects.
No all-base scan compensates for missing source separation proof. RD definition
identity includes semantic destination/remainder reasons and explicit Havoc reasons,
but not operation-header coverage diagnostics. Regional values never turn object or
operation metadata into sourceGap content, capture or additional targets. Solve/apply,
copy snapshot timing and correlated alternatives retain their actual semantics.

`sourceUnknownRemainder` (wire CALL `sourceValueRemainder`) reports coverage separately.
Value `effectiveUnknownRemainder` equals model remainder; CALL adds a genuine name
interpretation remainder. Source coverage alone does not open the calculated set.
Existing wire fields are retained under the pre-release policy. This is an explicit
semantic migration with coordinated producer/model/consumer pins, not a legacy mode.

The physical provider is still experimental and requires explicit opt-in. CLI/API
default is LOGICAL_ONLY; unsupported physical observations cannot trigger execution
or be labeled physical success. Existing validity/refusal and budget failures remain.
