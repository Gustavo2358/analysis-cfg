# EP-W1 — logical source evidence in the existing analyses

Rule: a validated `entry.possibilities@2` ObjectPlace can carry text support even
when its physical binding is open. It is a possibility with remainder, never an
exact initial value or a storage declaration. AIR normative authority is
`analysis-ir/especificacao/13-possibilidades-de-entrada.md` at the source lock.

RD and Regional Values add logical-object components to their existing states,
joins, entry boundary initialization and operation transfers. They use the same
DataflowSolver and BatchReplayer. Observations read converged state; they never
re-extract or reseed entry evidence. The logical components contain finite sets
of source/operation-supported values and events. Joins and updates union those
sets. With unproved binding, no transfer has authority for a logical strong kill.
Existing physical transfers and their MUST controls remain in force.

An explicit assignment can contribute its recognized text to its logical target.
An unproved alias or unknown effect opens uncertainty, without copying a literal
to another object. IDs select declared objects; they never prove separation.
No Cell, Region, allocation, byte range or disjointness premise is manufactured.

Preparation currently relates open objects conservatively to potential writes:
O(number of writes × number of open objects). This is finite and may retain
extra uncertainty. Scoped precision is an EP-W3 obligation. Logical/physical
mixed reads and generic policy mutations need further qualification in EP-W2–W5.

## Executed counterexamples and limits

The logical-binding RED oracle failed at RD/Regional Values with an empty
candidate set. The same oracle now preserves entry support across unknown effect
and unproved assignment; the latter retains old and new alternatives. Existing
MUST overwrite, conditional path and backedge controls still pass.

An independent source-profile counterexample found a separate encoding gate.
The SP producer now publishes recognized logical text without physical bytes,
and the lower sends it through this same AIR/state contract.

This proves LOCAL FIX and a bounded entry-preservation law. It does not qualify
all arbitrary constructs, failure containment, or the incident class. Those are
separate campaign waves. REAL CASE = NOT AVAILABLE.
