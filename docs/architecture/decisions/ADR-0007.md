# ADR-0007 — Java 21 e modelo AIR compartilhado via air-java

Status: `accepted`. Data: 06/09/2026. Implementação: inexistente.

## Contexto

O consumer precisa compartilhar o contrato Java com produtores/lowerers sem
duplicar a AIR. A inspeção de `air-java/main` confirmou um modelo imutável,
transport-independent e um validator estático alinhados à Analysis IR 2.0.0.

## Decisão

`analysis-cfg` adotará Java 21, Maven e nenhum recurso preview. O owner físico do
modelo Java AIR é `Gustavo2358/air-java`, commit
`2108294d9dfeb89d0019ce75fab27172b15a75b9`, coordenadas declaradas
`io.github.gustavo2358:air-java:0.1.0-SNAPSHOT`.

O kernel depende desse artefato e recebe sua
`io.github.gustavo2358.air.model.Publication`. Este repo não implementa cópias de
`Publication`, `Unit`, `Entry`, `Sequence`, `Operation`, `Instruction`,
`Terminator`, `TypeRef`, IDs, `Premise`, `DomainProofScope` ou outros tipos AIR.
`AirValidator` do mesmo artefato executa o preflight estrutural; os evals CFG
continuam independentes.

A versão `0.1.0-SNAPSHOT` é da biblioteca; `2.0.0` é da semântica AIR. O SHA fixado
torna a baseline inspecionada imutável. Como não há tag/release observada, o work
item de bootstrap deverá fechar resolução Maven reprodutível antes de compilar o
consumer, sem copiar fontes nem aceitar um SNAPSHOT flutuante silenciosamente.

## Alternativas rejeitadas

Java 17 por alinhamento incidental com o frontend; modelo AIR local ou bifurcado;
DTOs paralelos no lowerer/CFG; serialização JSON intermediária obrigatória; validator
AIR reimplementado pelo consumer.

## Consequências e validação

Uma biblioteca compilada com `--release 17` pode ser consumida numa JVM 21; não é
necessário alterar `proleap-poc` neste projeto. Gates futuros verificam target 21,
origem do tipo `Publication`, ausência de tipos AIR duplicados e de dependências de
transporte/frontend no kernel.

## Evidência

POM, API, documentação, gate offline, `mvn verify` e CI do `air-java` no SHA fixado;
Analysis IR 2.0.0 no commit normativo. Ver [fontes](../../sources/index.md) e
[toolchain](../../engineering/toolchain-and-modules.md).
