# ADR-0005 — Controle contextual é domínio

Status: `accepted-direction`. Data: 05/09/2026. Implementação: inexistente.

## Contexto

O CFG nasce independente e será integrado como módulo Maven. O harness precisa
distinguir direção de produto, proposta de desenho e código realmente existente.

## Decisão / proposta

Separar adjacência plana de caminhos com frames; controle local exige matching ou aproximação declarada.

## Alternativas rejeitadas

Retornos de uma porta conectados livremente a todos os callsites com claim preciso.

## Consequências e validação

Aplicar os [invariantes](../invariants.md), com teste de fronteira e casos negativos
antes de afirmar a capability. Não usar este ADR como autorização de implementação.
Propostas devem ser aceitas ou substituídas no primeiro discovery; alterações que
mudem semântica IR exigem proposta upstream, não apenas editar este ADR.

## Evidência

IR §05.5/7 e O-56–O-60. Consultar [fontes fixadas](../../sources/index.md).
