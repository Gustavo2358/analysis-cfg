it does not add grammar support or declare preserved clauses harmless. Twelve
factor combinations (encoding profile × physical offset knowledge × no operand /

admission with complete operation-owned precondition scope is allowed; the affected
operation loses MUST authority. Strict codec and projection policies still refuse.
Partial projection retains the original Publication and every occurrence, typed
known edges and conservative lazy unknown edges in the existing context/solver.
Unknown edges never target the entry seed node. No second solver is introduced.

Additional source verticals cover unknown statements/arguments/results, branch

and missing VALUE. Frozen historical sources cover USING, DISPLAY, SYNC,
SYNCHRONIZED, JUSTIFIED, BLANK WHEN ZERO, SIGN, two possible VALUEs with unknown
separation, computed/literal sites and exact overwrite.

## What this does not prove / independent remaining causes

This qualifies the tested architectural incident class, not every COBOL construct
or every codec expression. The parser must first publish a valid recognizable
source fact. Invalid literals, missing input containing the declaration, structural
invalidity and unsupported/unnegotiated model forms can still prevent analysis.
Resource exhaustion remains an explicit failure, never certified success.

Unknown allocation/alias may still open a whole unit when no narrower bound is
proved. A logical copy needs positive separation and known textual shape; slices,
multiple receivers and unproved alias do not acquire invented copy precision.
The generic AST JOHNDOE experiment proves downstream behavior, not grammar support
for a literal COBOL JOHNDOE keyword. Primary SP export selects a program unit;
multiple-unit input-gap tests prove isolation of the selected unit, not aggregate
primary export of every unit. Legacy CFG JSON v1–v3 cannot encode the new contextual
partial projection and explicitly refuse it; primary dependency JSON supports it.

Independent causes still capable of the symptom include a missing source fact,
unsupported target interpretation and a real complete executed overwrite. Tests
separate those from loss caused only by unrelated uncertainty.
