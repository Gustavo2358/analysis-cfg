# Molde para uma implementação posterior

Use somente após concluir/revisar o discovery e promover um item de backlog.

```text
Leia AGENTS.md e o manifesto/state do work item autorizado abaixo. Execute somente
o checkpoint indicado, com TDD e contexto relevante encontrado no harness/código.
Respeite fonte IR fixada, invariantes, source_scope, must_not_change e gates.
Não avance ao próximo checkpoint. Registre RED/GREEN, challenge, limites e handoff.
Work item: <ID existente e revisado>
Checkpoint autorizado: <checkpoint concreto>
```

Preencher campos não é dispensar review nem autorização. O molde não autoriza por si.
