# Leituras externas

A especificação normativa e a bibliografia estão no [índice de fontes](../sources/index.md).
Este diretório não contém uma fork do contrato IR. O cache opcional vai para
`.cache/analysis-ir/<commit>/` na raiz, ignorado por Git e pelos gates documentais.

Antes de implementação semântica, consultar a fonte fixada pela rota do work item.
Se a rede estiver indisponível, importar cópia local com hashes conferidos. Se não
houver fonte suficiente, registrar bloqueio em vez de inventar a regra.
