# Work Item Protocol

A política vigente é [LEAN HARNESS / GIT-IS-THE-RECORD](lean-harness.md).

Implemente no escopo autorizado, execute FAST, abra PR e obtenha revisão humana
quando a mudança justificar. Full é local e proporcional ao risco técnico.
Git/PR/testes registram o trabalho; receipts e certificados não condicionam avanço
ou fechamento. Registros antigos permanecem somente como história.
